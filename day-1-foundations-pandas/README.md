Welcome to **Day 1** of the **TensorOrbit Exploratory Data Analysis Bootcamp**! 🚀

Today, we will build the foundation for the rest of the bootcamp by exploring the basics of **Data Science**, understanding where **Exploratory Data Analysis (EDA)** fits into the data workflow, and getting hands-on with **Python and Pandas**.

### 2. Pandas Fundamentals

During the hands-on session, we will cover:

* Loading datasets with `read_csv()`
* Introduction to `read_excel()`
* Exploring datasets using:

  * `.head()`
  * `.tail()`
  * `.shape`
  * `.columns`
  * `.dtypes`
  * `.info()`
* Selecting columns
* Indexing with `.loc[]` and `.iloc[]`
* Boolean and conditional filtering
* Sorting data with `.sort_values()` and `.sort_index()`
* Descriptive statistics with `.describe()`
* Checking missing values with `.isnull().sum()`
* Exploring categorical data with `.value_counts()`
* Detecting and removing duplicates
* Handling missing values using:

  * `.fillna()`
  * `.dropna()`
* Data type conversion with `.astype()`
* Creating and modifying columns
* Renaming columns with `.rename()`
* Applying functions with `.apply()` and lambda functions
* String operations using the `.str` accessor
* Basic datetime handling with `pd.to_datetime()`
* Extracting year, month, and day from dates
* Grouping and aggregation with `.groupby()`
* Combining datasets using:

  * `.merge()`
  * `.concat()`
* Exporting data using `.to_csv()`
