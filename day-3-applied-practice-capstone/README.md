# 🔍 Guided EDA Workflow

During the guided walkthrough, we will work through a complete data analysis process using a sample business dataset.

## 1. Load the Data

* Import the required libraries.
* Load the dataset using Pandas.
* Examine the first few rows.

## 2. Understand the Dataset

We will explore:

* Dataset dimensions
* Column names
* Data types
* Missing values
* Descriptive statistics

Common commands may include:

```python
df.head()
df.shape
df.info()
df.describe()
df.isnull().sum()
```

## 3. Clean the Data

We will identify and address potential data quality issues, including:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent values
* Columns that require transformation

## 4. Explore the Data

Participants will use Pandas and NumPy to investigate the dataset and answer meaningful questions.

This may involve:

* Filtering records
* Sorting values
* Grouping and aggregation
* Calculating summary statistics
* Comparing categories
* Identifying distributions and patterns
* Exploring relationships between variables

## 5. Analyse the Data

We will look beyond individual values to identify:

* Trends
* Patterns
* Potential outliers
* Relationships between variables
* Correlations
* Interesting business insights

## 6. Visualise Findings

Participants will use Matplotlib to communicate their findings through clear visualisations.

Possible chart types include:

* Bar charts
* Line charts
* Histograms
* Scatter plots
* Boxplots
* Pie charts

Each visualisation should help answer a meaningful question about the dataset.

# 🎯 Capstone Kickoff

Day 3 also marks the beginning of the **TensorOrbit EDA Bootcamp Capstone Project**.

Teams will receive a business dataset and apply the skills learned throughout the bootcamp.

The objective is not simply to produce charts.

Teams should use data to identify a meaningful:

* Problem
* Pattern
* Trend
* Opportunity
* Relationship

They should then develop a recommendation based on their findings.

## Expected Deliverable

Each team should work towards presenting:

### 1. The Problem or Question

What are you investigating?

### 2. Data Exploration

What did you discover while exploring and cleaning the dataset?

### 3. Key Findings

What patterns, trends, or insights did you identify?

### 4. Visual Evidence

Which charts or visualisations support your findings?

### 5. Recommendation

Based on the analysis, what recommendation can you make?

# 💻 Independent Team Practice

After the guided walkthrough and capstone briefing, teams will work independently on their assigned dataset.

During this session, participants should:
