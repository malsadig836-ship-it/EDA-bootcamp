## 🔢 Part 1: NumPy

NumPy is a Python library used for efficient numerical computing and working with arrays.

During this session, we will cover:

### Creating Arrays

* `np.array()`
* `np.zeros()`
* `np.ones()`
* `np.arange()`

### Array Indexing and Slicing

* Indexing 1D arrays
* Indexing 2D arrays
* Array slicing

### Reshaping Arrays

* Using `.reshape()`

### Vectorised Operations

Performing element-wise operations across arrays:

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`

### Boolean and Fancy Indexing

* Conditional selection using `arr[condition]`
* Fancy indexing using index arrays
* Using `np.where()`

### Sorting Arrays

* `np.sort()`

### Statistical Functions

* `np.mean()`
* `np.median()`
* `np.std()`
* `np.var()`

### Percentiles and Quartiles

* Using `np.percentile()`

### Outlier Detection

We will introduce two common approaches:

* Z-score method
* Interquartile Range (IQR) method

### Correlation

* Creating correlation matrices using `np.corrcoef()`
* Understanding relationships between variables
* Correlation vs. causation

## 📊 Part 2: Matplotlib

After analysing numerical data with NumPy, we will learn how to turn those findings into meaningful visualisations.

### Core Chart Types

We will explore:

* 📈 Line charts
* 📊 Bar charts
* 📉 Histograms
* 🔵 Scatter plots
* 📦 Boxplots
* 🥧 Pie charts

We will also discuss **when to use each chart type**.

### Chart Customisation

Learn how to improve the readability of your visualisations using:

* Titles
* Axis labels
* Legends
* Colours
* Markers
* Grid lines

### Subplots

* Creating multiple charts using `plt.subplots()`
