# TensorOrbit Exploratory Data Analysis Bootcamp 🚀

Welcome to the official repository for the **TensorOrbit Exploratory Data Analysis (EDA) Bootcamp**.

This hands-on bootcamp introduces participants to the foundations of **Data Science and Exploratory Data Analysis using Python**. Throughout the programme, participants will learn how to work with data using **Pandas**, perform numerical analysis with **NumPy**, and communicate insights through visualisations using **Matplotlib**.

The bootcamp follows a connected learning journey, progressing from foundational concepts to hands-on analysis and a team-based capstone project.

# 💻 Getting Started

This bootcamp is designed to be accessible directly through **Google Colab**, so participants do not need to install Python or configure a local development environment.

For each session:

1. Open the relevant day's folder.
2. Read the session overview.
3. Review the presentation slides.
4. Open the hands-on notebook using the **Google Colab** button.
5. Follow along with the instructor.
6. Complete the guided exercises and practice activities.

# 🎯 Learning Outcomes

By the end of the TensorOrbit EDA Bootcamp, participants should be able to:

* Understand the fundamentals of Data Science and Exploratory Data Analysis.
* Load and explore datasets using Pandas.
* Clean and prepare data for analysis.
* Perform filtering, grouping, aggregation, and data transformation.
* Work with numerical data using NumPy.
* Calculate descriptive statistics and identify potential outliers.
* Explore relationships and correlations between variables.
* Create meaningful visualisations using Matplotlib.
* Combine Pandas, NumPy, and Matplotlib in a complete EDA workflow.
* Identify meaningful patterns and insights from real-world datasets.
* Communicate findings and develop data-driven recommendations.
* Collaborate with a team on a practical data analysis project.
